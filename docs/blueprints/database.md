# Database Implementation Blueprint (PostgreSQL Edition)

## 1. Data Type Standards

Strictly enforce these PostgreSQL-native types to ensure precision for GPS calculations and financial logic.

| Category | Type | Rule |
| --- | --- | --- |
| **Primary Keys** | `BIGINT` | Use `GENERATED BY DEFAULT AS IDENTITY`. |
| **GPS / GIS** | `GEOGRAPHY(Point, 4326)` | **Mandatory** for all coordinates. SRID 4326 is the GPS standard. |
| **Financials** | `DECIMAL(19, 4)` | Mandatory for pricing models. **Zero rounding allowed in DB.** |
| **Logic/Flags** | **`BOOLEAN`** | Use native Postgres `BOOLEAN` (true/false) instead of `TINYINT`. |
| **Strings (S)** | `VARCHAR(255)` | Default for metadata and slugs. |
| **Strings (L)** | `TEXT` | PostgreSQL `TEXT` has no performance penalty over `VARCHAR`; use for all long-form content. |
| **Flex Specs** | **`JSONB`** | **Strictly use `JSONB**` (Binary JSON) for faster processing and indexing of product attributes. |

## 2. Spatial Indexing & Integrity

* **Initialization**: The first Flyway migration (`V1`) **MUST** execute `CREATE EXTENSION IF NOT EXISTS postgis;` to enable spatial features.
* **Encoding**: Use `UTF8` for all databases to support multi-language product specs and symbols.
* **GIS Indexing**: All `GEOGRAPHY` columns MUST have a **GIST (Generalized Search Tree)** index to enable high-speed proximity queries for GPS quoting.
* **Physical FKs**: Mandatory database-level Foreign Key constraints for all relationships.
* **Junction Tables**: Pattern: `[prefix]_[table_a]_[table_b]`. Must include `id` and audit columns.
* **Normalization**: Mandatory **3NF (Third Normal Form)**. Use `JSONB` only for non-relational, varied attributes (e.g., specific door mesh specs).

## 3. Tiered Audit Strategy

* **Tier 1 (Inline)**: All tables MUST include `created_at`, `updated_at`, `created_by`, `updated_by`.
* **Tier 2 (Suffix)**: Mandatory for `fin_`, `sys_roles`, and `qte_quotations`.
* **Pattern**: `[feature_prefix]_[table_name]_audit`.
* **Content**: Full row snapshot + `audit_action` (INS/UPD/DEL) + `audit_timestamp`.

## 4. Functional Namespacing (3-Letter Prefixes)

* **`sys_`**: Authentication, Accounts, Sessions, Permissions.
* **`cat_`**: Catalog, Products, Gallery, Categories.
* **`qte_`**: Inquiries, Quotations, Customer Profiles.
* **`fin_`**: Financial base costs, Distance rates, Pricing constants.
* **`ops_`**: Staff job listings, Internal operation logs.

## 5. Deletion & Privacy Policy

* **Soft Delete**: Mandatory for **Assets** (`cat_`, `qte_`, `sys_accounts`). Use `is_deleted = BOOLEAN`.
* **Hard Delete**: Allowed ONLY for **Transients** (Session tokens, temporary cache).
* **Encryption**: Store only salted **BCrypt** hashes for passwords.

## 6. Flyway Lifecycle

* **Naming**: `V[YYYYMMDDHHMMSS]__Description.sql`.
* **PostGIS Setup**: The very first migration (`V1`) MUST execute `CREATE EXTENSION IF NOT EXISTS postgis;`.
* **Prohibition**: `ddl-auto` is strictly forbidden. Schema is managed via versioned migrations only.
* **Repeatables**: Use `R__` prefix for database views, triggers, or seed data.
